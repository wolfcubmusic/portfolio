# WOLFART BOOKS — Соль мёртвых богов

Финальный концепт книжного лендинга, 28 октября 2026 года. Морская готика варианта B, утверждённая смотрительница, маленький дракон и золотая типографика готовой обложки. Автор концепта — Дарья Тишина.

[Открыть лендинг](https://wolfcubmusic.github.io/portfolio/books/salt/) · [Кейс WOLFART](https://wolfcubmusic.github.io/portfolio/books/salt/case.html)

## Страницы

- `index.html` — лендинг: история, тизер, герои, дракон, атлас, фрагмент, автор и выбор издания.
- `case.html` — кейс WOLFART: дизайн, тексты и контентная структура.
- `press-kit.html` / `press-kit.md` — описание книги и авторской концепции для партнёров.
- `salt-assets/` — локальные WebP, CSS, JavaScript, шрифты и лицензии.
- `TEASER_PROMPT.md` — бриф для последующей видеоверсии тизера.

В этом репозитории готовый сайт лежит в `books/salt/`. Сборка, зависимости и API-ключи не нужны; можно открыть HTML напрямую или использовать любой статический сервер. Внутренние пути относительные, размещение в подпапке поддерживается.

## Что работает

Единый режим чтения из всех CTA; закрытие окон по Escape и возврат фокуса; мобильное меню; три локации атласа со сменой изображения, описания и клавиатурной навигацией; просмотр обложки; иллюстрированный тизер на 32 секунды с ручным запуском, паузой и перемоткой; два разных сценария выбора издания; подготовка письма по теме сотрудничества; копирование email с понятным запасным вариантом, если браузер не даёт доступ к буферу.

Тизер собран из иллюстраций и работает без звука. Это не сгенерированное видео. Режим уменьшения движения учитывается; автоматического воспроизведения на странице нет.

Проверены локальные пути, якоря, уникальность ID, декодирование изображений и синтаксис JavaScript. В Chrome вручную проверены чтение, переход к изданиям, обе кнопки форматов, контакт по теме, запасной способ копирования email, атлас мышью и клавиатурой, запуск/пауза/перемотка тизера. Проверены адаптивные контейнеры 320, 390, 768, 1024 px и настольная ширина 1363 px; переполнения документа не обнаружено. Safari и Firefox в этой сессии не проверялись.
