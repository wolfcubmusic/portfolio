# После сигнала / WOLFART BOOKS

Демонстрационный адаптивный промолендинг психологического триллера. Первый из двух жанровых проектов WOLFART BOOKS для портфолио и питчинга издательствам и литературным агентствам.

**Открыть:** https://wolfcubmusic.github.io/portfolio/books/after-signal/

Книга, автор Алиса Север, персонажи, санаторий и сюжет вымышлены. Проект не представляет реального издателя. Реальной покупки, аудиокниги, сбора контактов или обработки платежей нет.

## Идея

Она узнала свой голос. Но не помнила этих слов.

Двадцать лет назад в санатории «Берег» исчезла сестра Веры. Найденная кассета возвращает героиню к событиям одной ночи. Визуальная метафора — вторая сторона плёнки, другая версия памяти.

## Посетительский сценарий

1. Жанр, название, автор и интрига на первом экране.
2. Аннотация раскрывает конфликт без спойлеров.
3. Три интерактивные улики — кассета, ключ и фотография — знакомят с миром.
4. Первые страницы и полный демонстрационный отрывок в читательском окне.
5. Атмосферная пауза: «Море возвращает всё. Кроме той ночи».
6. Авторский голос с явным обозначением вымышленного автора.
7. Обложка и выбор бумажного, электронного или аудиоформата. Демонстрация объясняет, куда привёл бы переход в реальном проекте.

## Реализация

Чистые HTML, CSS и JavaScript. Сборка и пакеты не нужны. Все шрифты и изображения локальны. Страница работает при открытии `index.html`; для корректной проверки URL и метаданных лучше использовать статический HTTP-сервер.

- `index.html` — структура, тексты, диалоги.
- `style.css` — арт-дирекшн, сетка и адаптивы.
- `script.js` — улики, меню, диалоги, индикатор чтения и мягкие появления.
- `assets/` — WebP, изображение для социальных сетей, SVG-иконка, шрифты и лицензии OFL.
- `ART_DIRECTION.md` — идея, дизайн-система и промпт изображения.
- `QA.md` — объём выполненных проверок и ограничения.

Клавиатура: Tab для перехода между элементами; стрелки, Home и End для улик; Escape для закрытия меню и диалогов. Уменьшение движения поддерживается через `prefers-reduced-motion`.

## Публикация

В действующем репозитории `wolfcubmusic/portfolio`, ветка `main`, папка `books/after-signal/`. Сайт использует существующий GitHub Pages. Для переноса достаточно скопировать всю папку и обновить canonical/og:url/og:image под новый адрес.

Внешние библиотеки, аналитика, cookie-баннер, CMS и серверные функции не используются. Шрифты Manrope и Prata распространяются по SIL Open Font License; тексты лицензий лежат рядом со шрифтами.
